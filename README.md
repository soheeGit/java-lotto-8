# java-lotto-precourse

# 로또 미션

## 기능 목록

### 1. 로또 구입 기능
- [x] 구입 금액을 입력받는다.
    - [x] 구입 금액이 1,000원 단위인지 검증한다.
    - [x] 구입 금액이 1,000원으로 나누어 떨어지지 않으면 예외를 발생시킨다.
    - [x] 구입 금액이 양수인지 검증한다.
- [x] 구입 금액에 따라 로또를 발행한다.
    - [x] 구입 금액 / 1,000 = 로또 구매 개수를 계산한다.
    - [x] 각 로또마다 1~45 사이의 중복되지 않는 숫자 6개를 생성한다.
- [x] 발행한 로또 수량과 번호를 출력한다.
    - [x] 로또 번호는 오름차순으로 정렬하여 출력한다.

### 2. 로또 번호 생성 기능
- [x] 1~45 사이의 중복되지 않는 숫자 6개를 무작위로 생성한다.
- [x] 생성된 로또 번호를 검증한다.
    - [x] 로또 번호가 6개인지 검증한다.
    - [x] 로또 번호가 1~45 범위 내에 있는지 검증한다.
    - [x] 로또 번호에 중복이 없는지 검증한다.

### 3. 당첨 번호 입력 기능
- [x] 당첨 번호를 입력받는다.
    - [x] 쉼표(,)를 기준으로 번호를 구분한다.
    - [x] 입력된 번호가 6개인지 검증한다.
    - [x] 입력된 번호가 1~45 범위 내에 있는지 검증한다.
    - [x] 입력된 번호에 중복이 없는지 검증한다.
    - [x] 숫자가 아닌 값이 입력되면 예외를 발생시킨다.
- [x] 보너스 번호를 입력받는다.
    - [x] 보너스 번호가 1~45 범위 내에 있는지 검증한다.
    - [x] 보너스 번호가 당첨 번호와 중복되지 않는지 검증한다.
    - [x] 숫자가 아닌 값이 입력되면 예외를 발생시킨다.

### 4. 당첨 확인 기능
- [ ] 구매한 각 로또 번호와 당첨 번호를 비교한다.
    - [ ] 일치하는 번호의 개수를 센다.
    - [ ] 보너스 번호 일치 여부를 확인한다.
- [ ] 당첨 등수를 판정한다.
    - [ ] 6개 일치 → 1등 (2,000,000,000원)
    - [ ] 5개 일치 + 보너스 번호 일치 → 2등 (30,000,000원)
    - [ ] 5개 일치 → 3등 (1,500,000원)
    - [ ] 4개 일치 → 4등 (50,000원)
    - [ ] 3개 일치 → 5등 (5,000원)
    - [ ] 그 외 → 낙첨

### 5. 당첨 통계 출력 기능
- [ ] 각 등수별 당첨 개수를 집계한다.
- [ ] 당첨 내역을 출력한다.
    - [ ] 3개 일치부터 6개 일치까지 출력한다.
    - [ ] 각 등수별 당첨 금액과 개수를 출력한다.

### 6. 수익률 계산 기능
- [ ] 총 당첨 금액을 계산한다.
    - [ ] 각 등수별 당첨 금액 × 당첨 개수를 합산한다.
- [ ] 수익률을 계산한다.
    - [ ] (총 당첨 금액 / 구입 금액) × 100
    - [ ] 소수점 둘째 자리에서 반올림한다.
- [ ] 수익률을 출력한다.

### 7. 예외 처리 기능
- [ ] 잘못된 입력에 대해 IllegalArgumentException을 발생시킨다.
- [ ] 에러 메시지는 "[ERROR]"로 시작한다.
- [ ] 예외 발생 시 해당 부분부터 입력을 다시 받는다.

## 실행 예시
```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```
